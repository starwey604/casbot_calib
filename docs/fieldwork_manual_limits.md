# 用“限制设置”调整手动调参台

> ROS GUI 历史记录。main 的图形入口已迁到 [SHM 本机调参台](shm_gui.md)；本文旧验收/性能脚本在 ROS 备份分支查看。

点击顶部 **限制设置**。先修改草稿，再点 **应用设置**；每个数值都有滑条和精确输入框。滑条长度是便捷编辑范围，不是隐藏的硬上限，较大的值可直接输入。

“修改范围”可选全轴默认或当前所选轴覆盖。逐轴字段可切回“继承全轴默认”；位置边界可选各轴URDF或自定义值。URDF只是模型参考，未冒充设备读回限位。

## 四页分别在什么时候生效

| 页面 | 可调内容 | 生效时机 |
| --- | --- | --- |
| 反馈观察 | 每轴位置下/上限（只告警/记录）、速度绝对值及速度越限动作 | 当前发送器确认新版本后在线生效 |
| 目标输入 | 每轴位置下/上限、目标速度绝对值、前馈effort绝对值、Kp/Kd上限 | 下次开始控制；当前发送继续用起始快照 |
| 等待与通信 | 启动/停止速度与持续稳定时间、停止观察时限、反馈/模式回调超时、模式切换等待、窗口心跳、记录器启动等待、发送频率、控制时长、短轨迹范围 | 下次开始控制 |
| Mock | 前馈接受上限、Kp/Kd接受上限、物理内核PD+前馈总力矩限幅、断流看门狗 | 下次 `gui --mock` 启动，不自动重启当前实例 |

**位置反馈越界始终只告警、记录，不停止发送。速度反馈越限默认仅告警**，可以全轴或逐轴选择“结束本次控制”；此动作只作用于速度，不作用于位置。结束后只读连接继续，点“重读 / 新控制”建立另一次控制。通信、SDK、模式和心跳故障仍结束当前控制。

顶部状态列出触发轴、反馈值、阈值与单位；恢复后显示已回到观察范围。选轴的调参区显示发送器已确认的观察范围/动作。设置窗分别显示保存版本、观察确认版本和本次输入/等待/通信快照版本；等待回执时不显示为已应用。无效草稿就地报错，保留原有效设置。

## 默认值与含义

- **反馈观察速度：1.5 rad/s**（新profile默认）；它与目标速度输入范围独立。改变速度目标不意味着真实机器人会按该速度限速。旧工作区保留原阈值，可在此修改。
- 启动停稳：全部轴 `|dq|<0.2 rad/s`，持续0秒；未满足时显示轴和值并等待，可取消。此为2026-11-14用户确定的统一现场默认，覆盖H1–H4、K系列、手动与回零；显式保存的设置值不被回写。
- 停止观察：全部轴 `|dq|<0.02 rad/s` 持续0.1秒，最多观察3秒；不满足时报告未确认停稳，不关闭GUI。停止发布不是主动制动或回位。
- 回调超时：关节2秒、模式3秒；模式切换等待3秒、窗口心跳2秒、记录器启动等待10秒。这里是本地接收间隔，不是设备采样年龄。新会话采用新profile默认；已有工作区/显式profile保留原值，可在此页修改后于下次控制生效。
- 发送频率可选100/250/500Hz，默认沿用profile。控制最长时长0表示不限；主动设置时长后按正常结束处理。前置反馈/服务发现等待没有统一10秒截止。
- 短轨迹幅度上限1°，时长2–12秒，实际幅度/时长仍由主界面设置；只检查自己的输入/端点，不是离线碰撞认证。
- 输入范围默认：位置按URDF、速度沿用profile、effort±10Nm、Kp0–1000、Kd0–100。边界可调；首次实际反馈/增益不会被夹取到这些范围内。越界时列出轴和值，先修正目标或范围，不能开始发送。
- 手动Mock默认：前馈接受100Nm，Kp1000/Kd100，总请求限幅100Nm，看门狗0.1秒。前馈接受与总输出饱和是不同层；总请求限幅包含PD。SDK反馈没有饱和标志，GUI不读取私有plant真值来代替设备反馈。

修改任何范围都不会夹取或移动当前目标。尚未发送时可以逐项修正多个冲突；发送中非法目标不替换最后有效指令。已知Mock接受范围另行检查并指明“本次实例”；改变下一次Mock配置不会扩大当前实例的能力。实机接受范围未知，不套用Mock数值。

## 保存、恢复与实现位置

- `settings/versions/000000NN.json`：不可变策略版本，绑定模型和14轴顺序；不修改封存的连接/profile。
- 每次控制 `runs/*/settings_initial.json`：本次完整起始设置。
- `runs/*/capture/execution/settings_applied.csv`：原生发送器实际接受的完整操作/观察/等待参数与版本/接收时间。在线更新保留本次输入/通信快照，只替换观察字段。发送频率/记录器启动等待在起始JSON与请求配置中留档。
- `runs/*/capture/execution/observed_limits.csv`：位置/速度越限与恢复；越限集合变化立即记录，持续越限约每秒更新，原始反馈仍完整保留。`observed_action`字段从本轮起只控制速度动作；原生结果另记`position_limit_action=warn`，旧记录不改写。
- 新手动控制CSV由有界异步线程写入，正常结束排空；队列满/写入失败时停录告警，不改变手动发送。导出标记已完成/活动/暂停前缀，详见[写盘停顿修复](fieldwork_stale_mode_debug.md)。
- 本次指令与反馈、逐轴越限事件仍按原格式保存；“保存会话”同时归档设置。旧记录没有策略时明确标记，不补写新默认为旧实际值。
- 下次自建Mock配置写入 `$CASBOT_FIELDWORK_CACHE/mock_next.json`，未设置该变量时位于XDG状态目录的`casbot-calib/fieldwork/`。只保存设备层设置和模型绑定，不保存域号、目标或运动命令；不改独立SDK Mock的启动配置。

数据/校验：`fieldwork_settings.py`；编辑器：`fieldwork_settings_gui.py`；原生解析/回执：`manual_policy.hpp`与`position_executor.cpp`。原始手动字段仍直接发送，无模型重力/摩擦补偿，没有“停止发包伪装成暂停”的分支。面板不回写H1–H4/S2/S3/S4；现场CLI的起点重规划及2秒/3秒新默认见[实机联调路径](hardware_execution_path.md)。

本轮没有加入位置参考平滑/暂停，也没有把Mock全部数值内核参数搬到面板；积分、采样、惯量、摩擦、延迟等仍在`configs/fieldwork_mock.yaml`中校验。见[原四轮计划](fieldwork_limits_behavior_plan.md)中的后续范围。

## 已验证的行为

`artifacts/fieldwork_limits_v4/verification.json`：当时版本的四页面非视觉运行（包括保存快照只读翻页）、0.3秒自定义心跳终止；默认告警不停流、阈值在线确认与恢复、非法在线输入策略拒绝、逐轴结束、正常定时结束、旧故障控制锁定/独立只读保留、下一次控制采用新输入范围、保存完整生效策略通过。该历史版本的结束动作曾包含位置；本轮位置始终只记录，原记录保留。未进行窗口外观验收。

`artifacts/fieldwork_mock_settings_v1/verification.json`：保存设备层配置不改当前实例，下一次自有Mock实际接收新的前馈/Kp/Kd/总请求/看门狗参数通过。原生设备测试独立验证总请求限幅7Nm时，120Nm前馈叠加PD后实际输出仍按7Nm截断。以上均为私有localhost Mock，不连接实机。
