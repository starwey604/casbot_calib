# 采完探针后，判断 SDK 反馈会怎样影响惯量辨识

使用只读评估器，在同一条公开反馈上施加相同退化，再比较两条路线：

- **A：直接同带宽拟合**。沿用已有局部惯量、粘性、常量和慢漂移回归，不作相位修正。
- **B：多频频响拟合**。沿用已有双频惯量、粘性与单个等效相位联合估计。

输出每轴、每条记录的惯量变化、正反向一致性，以及在已测离散点中首次超过 **10%** 的扰动档位。分析不连接 ROS、不补采、不写候选，也不影响 H1–H4 采集推进。

现场优先判断 A 能否使用时，先按 [fieldwork 的 A 优先流程](../fieldwork/README.md#4-用已保存的数据判断能否优先采用-a) 整理 GUI 保存数据、IMU 与实际发送档位。下述专用探针评估器继续用于反馈退化压力和 Plan B 对照。

## 运行现有记录

在仓库根目录使用已经配置好的 Humble 环境。以下三份本机记录不随 Git 分发；缺失时提供实际存在的同类会话，不能以新数据冒充历史记录。

```bash
bash scripts/humble/container.sh casbot-fieldwork sensitivity \
  --source artifacts/sdk_wrist_roll_dual_protocol_v2 \
  --source artifacts/sdk_wrist_roll_c00_pair_v1 \
  --source artifacts/sdk_wrist_pitch_c00_pair_v1 \
  --output artifacts/sdk_feedback_sensitivity_new
```

也可用 `python scripts/humble/assess_sdk_feedback.py`，参数相同。`--source` 可重复；输出必须是所有输入会话之外的新目录。只读入口不需要域号、SDK overlay 或 GUI。

先看 `report.md`，需要完整数字时看 `case_results.csv` 或 `report.json`：

- `protocol.json`：读取观测之前登记的完整扰动清单、随机种子、路线与指标定义。
- `report.md`：未扰动惯量／方向差、各类退化首次观测越界点、组合退化和数学反例。
- `case_results.csv`：每条记录×扰动×路线的惯量、等效相位、相对变化及不可用原因。
- `report.json`：完整数值、处理统计、方向差、离散敏感性曲线和实际输入路径。

退出码 0 表示分析已完成，**不是惯量验收通过**。超过 10% 或某条路线不可辨识会出现在报告内，不成为采集门禁；输入损坏／不支持或任务未完成则非零退出。

## 独立会话复测：复用旧评估，不重复拟合

给新会话追加 `--reference-assessment 旧评估目录`，即可在 `cross_session/report.md` 比较同方向惯量、会话内正反差、跨方向差及 b／等效相位变化。配方与有效模型／尺度／PD 必须对应；新运行由不同私有端点和接收历史留证。原来的单会话用法不变。

右腕 roll 的[独立两条复测](sdk_wrist_roll_repeat.md)已完成：同方向跨会话最差 A 6.037%、B 7.302%；B 的跨会话含跨方向最差为 10.829%，不能据此宣布所有比较都通过。

随后完成[四条双频记录的跨频失配诊断](sdk_roll_frequency_mismatch.md)，提供只读频响替换、窗口敏感性和低通假设剖面入口；结果支持先设计额外验证频点，不支持把约 1.9ms 拟合漂移直接作为硬件延迟修正。

## 输入范围

当前支持封存 SDK 探针协议：单频 pair、roll screen、双频 roll v1／v2。自动跟随起点重规划后的实际 plan／capture，核对原有封存与执行绑定，从公开 `feedback.csv` 重建观测。模型、轴顺序、力矩换算和重力方向沿用记录配置。

单频 pitch／roll 用来对照 A 的敏感度。B 需要至少两个已声明、实际执行的激励频点；不会把单频的噪声或谐波当作第二个已知激励。

当前不直接接任意 GUI 手动录像／拖动记录。GUI 虽已保存足够的原始字段，仍需为这类输入显式提供测量窗、激励频点和前序模型，再接适配器。现有 Mock 的重力／摩擦夹具也不能默认成为实机先验。

## 相同扰动怎样实现

每个条件只生成一份内存中的退化观测，A／B 共用同一次 `probe_problem` 结果。使用原完整测量窗、共同 Fourier 带宽、解析速度导数、相同时间行和权重，之后两条路线分别估计。A 使用时间域全部处理结果，B 使用声明频点的复数分量；残差定义不同，不能直接比较两个残差数值来选路线。

| 扰动 | 具体含义 |
|---|---|
| 力矩相对时移 | ±0.5／1／2／3／5／8／10／15ms；在已接收力矩波形上线性插值，正号表示向前评估 |
| 额外共同固定缓存 | 1–50ms 离散周期、两个缓存相位；q／dq／effort 共同保持最近已到达行 |
| 力矩独立缓存 | 3／5／10／20ms，运动字段不变 |
| 位置／速度字段滞后 | 分别额外滞后 1／3／5／10ms，其它字段不变 |
| 随机刷新 | 平均周期 2／5／10／20ms，每次刷新间隔均匀分布于 0.5–1.5 倍周期；共同／力矩独立两类 |
| FIFO 到达抖动 | 额外延迟均匀分布于 0–1／3／5／10ms；保留消息顺序，后到消息可成簇送达 |
| 停更 | 5–100ms，测量窗内三个位置；保留发布行，分别保持全部字段或仅力矩 |
| 接收空窗 | 5／20／50／100ms，三个位置；删除对应发布行，与持续发布旧值分开 |
| 力矩低通 | 1–20ms 一阶滤波时间常数，按不均匀接收网格作 ZOH 精确递推 |
| 力矩尺度 | 换算后的 Nm 施加 ±1／2／5／10／20% 增益偏差，不重复应用零偏／尺度 |
| 力矩噪声 | 0.02／0.05／0.1／0.2mNm，5ms 相关块；重复发布不当作独立噪声样本 |
| 组合退化 | 额外共同缓存 5ms＋力矩低通 5ms＋增益 −5%，再加 1／3／5ms 力矩滞后 |

随机项固定使用种子 11、23、37。同一条件的随机实现由 A／B 共享。种子／缓存相位／停更位置是有限压力集，不是概率置信区间。

所有退化均叠加在**已经存在未知缓存和滤波的公开记录**上。共享缓存 5ms、力矩错位 5ms、低通时间常数 5ms 是三件不同的事；不能把输出里的额外扰动阈值当作真实设备缓存容限。

## 怎样选择 A／B

优先使用在关心的退化范围内稳定、假设较少的 A。若 A 对字段错位明显敏感而 B 稳定，则用 B 做独立会话复测，并比较 J、粘性项和等效相位能否重复。相位参数只解释观测模型，不写回时间戳，也不反推真实硬件延迟。

B 对纯相位的改善不覆盖未知尺度／滤波。两条路线都稳定，也可能共同带有尺度偏差；两条都不稳定或不可辨识，则继续针对该轴补充观测证据／重新设计激励，而不是挑残差较小的一条。

评估报告明确区分：

1. **相对变化**：每条路线对自己的未扰动 J，分母下限为原 1e-6 kg·m²；原 10% 数值用于敏感性评价。
2. **正反差**：同一源会话、相同扰动下，以负向 J 为分母；另行报告。
3. **绝对误差**：现有公开数据不能直接给出。本报告只在真值已知的独立数学对照中计算，未读 Mock 私有真值。
4. **完整 R2**：本轮是局部单轴结果，不替代原 128 点的完整刚体删构型／删批次验收。

阈值表同时保留不可用／相位分支边界。只报告“首次观测越界”，不对离散点插值、不假定误差单调、不把“最大测试点未越界”写成连续安全保证。稳定性、方向一致性和独立复测共同决定下一步；反馈本身不能给未知真实时延一个可靠上界。

- `sdk_feedback_sensitivity.py`：封存公开记录读取、配对评估、报告和只读 CLI。

## 本轮结果：B 能缓解相位错位，但不能包办缓存和滤波

本机报告：`artifacts/sdk_feedback_sensitivity_v1/report.md`；独立数值复核：`artifacts/sdk_feedback_sensitivity_verification_v1/verification.json`。

使用已有双频 roll、单频 roll、单频 pitch 正反共 **6 条记录**，每条 **163 个条件**，共 978 个配对评估条件。1956 个路线结果中，1294 个有可用数值、652 个为单频 B 结构性不可辨识、10 个在强退化下数值不可用；没有把这些不可用项丢掉或视为通过。

下面只比较**同一双频 roll 数据**，取所列扰动条件中的最差值：

| 额外退化 | A 对自身基线变化 | B 对自身基线变化 | A 正反差 | B 正反差 |
|---|---:|---:|---:|---:|
| 共享缓存 5ms，两个相位 | 3.961% | 2.742% | **13.023%** | **13.354%** |
| 力矩相对错位 ±5ms | **27.226%** | 0.211% | 18.140% | 9.284% |
| 力矩一阶低通 5ms | **31.809%** | 5.914% | 18.958% | **10.545%** |
| 力矩增益 ±10% | 9.183% | 9.201% | 9.891% | 9.032% |
| 共享缓存 5ms＋低通 5ms＋增益 −5%＋力矩滞后 5ms | **63.953%** | **10.027%** | 33.654% | 11.529% |

未扰动时 A／B 正反差分别为 9.810%／8.958%，本来就离 10% 不远。因此共享缓存再增加 5ms 时，虽然各自变化都小于 4%，方向一致性已经越过 10%。**不能只拿一列“敏感度小”推荐直接使用。**

离散扫描中，双频数据上 A 对力矩相对时移首次在 2ms 越界，B 在已测 ±15ms 内未越界；低通首次越界为 A 2ms、B 8ms。额外共享固定缓存则是 A 20ms、B 15ms，B 并非对所有退化都更强。单频 roll／pitch 的 A 相对时移首次越界分别为 3ms／8ms；它们不能与双频 B 当作同一数据的优劣比较。

**本轮选择建议：将 B 保留为字段相位错位明显时的优先复测路线，同时保留 A 作为简单对照。** 下一项辨别力最高的现场／Mock 数据是独立会话的同配方正反复测，而不是继续调一个时移使本批结果更好。共同缓存、滤波与尺度仍分别评价；本轮没有取得实机缓存上界，也没有完成正式 R2。

验证：83 项相关 Python 测试通过。六条未扰动 A、两条未扰动 B 与历史结果的惯量差均为 0；七个代表扰动的独立线性／一维相位剖面算法与主实现一致，B 惯量最大差约 1.69e-13 kg·m²。只读隔离、单频秩缺失、非单调阈值及“自身稳定但方向超界”的汇总行为均有检查。
