# 📊 专用探针评估：SDK 反馈退化对腕部惯量辨识的影响 (`sensitivity`)

如果现场采集了专门的单频或双频腕部探针数据（`sdk_wrist_probe`），可以使用本工具对同一条公开反馈自动叠加 **12 大类、163 种人为退化条件**，正面对比两条惯量辨识路线的抗干扰能力：

* **路线 A（直接同带宽拟合）**：在时域使用有限窗 Fourier 基 + 二次漂移统一处理力矩与运动，不做相位修正。
* **路线 B（多频频响联合拟合）**：利用两个以上声明激励频点的复数响应，联合估计惯量 $J$、粘性摩擦 $b$ 与单个等效通道相位差 $\delta$。

> 💡 **日常 GUI 录制数据请先用 `a-evidence`**：如果你刚用 GUI 调参台录了短轨迹或手动控制数据，请先按 [现场联调手册第 4 节 (`a-evidence`)](../fieldwork/README.md#4-用已保存的数据评估手腕惯量辨识能力a-evidence) 分析。本工具专门用于标准封存探针（`casbot_sdk_wrist_*`）的全面退化压力测试。

---

## 🚀 一、运行命令

在仓库根目录下运行（支持传入多个 `--source` 探针会话目录，输出目录不能提前存在）：

```bash
# 1. 对单次或多次探针会话做 163 项退化敏感性评估
bash fieldwork/run.sh sensitivity \
  --source artifacts/sdk_wrist_roll_dual_protocol_v2 \
  --source artifacts/sdk_wrist_roll_c00_pair_v1 \
  --source artifacts/sdk_wrist_pitch_c00_pair_v1 \
  --output artifacts/sdk_feedback_sensitivity_new

# 2. 跨会话复测对比（加上 --reference-assessment 指向旧评估目录）
bash fieldwork/run.sh sensitivity \
  --source artifacts/sdk_wrist_roll_repeat_v1 \
  --reference-assessment artifacts/sdk_feedback_sensitivity_v1 \
  --output artifacts/sdk_wrist_roll_repeat_comparison_new
```

### 输出文件说明
* `report.md`：最直观的汇总报告，列出未扰动基线惯量、正反方向差异、以及每类退化**首次使惯量偏差超过 10% 的临界档位**。
* `cross_session/report.md`：当传入 `--reference-assessment` 时生成，对比两次独立运行同方向、跨方向的惯量重复性与相位漂移。
* `case_results.csv` & `report.json`：每条记录 × 163 个退化条件 × A/B 路线的完整数值明细。

## 🧪 二、12 类模拟退化条件一览

评估器在内存中对公开反馈叠加以下退化，并同时交给路线 A 和路线 B 求解：

| 退化类型 | 测试档位与含义 |
| :--- | :--- |
| **1. 力矩相对时移** | `±0.5 / 1 / 2 / 3 / 5 / 8 / 10 / 15 ms`（线性插值平移力矩波形，测试纯通道延迟/超前） |
| **2. 额外共享固定缓存** | `1 ~ 50 ms`（`q / dq / effort` 共同按固定周期零阶保持，模拟底层缓存未刷新） |
| **3. 力矩独立缓存** | `3 / 5 / 10 / 20 ms`（仅力矩通道零阶保持，运动通道不变） |
| **4. 位置/速度单独滞后** | `1 / 3 / 5 / 10 ms`（分别让位置或速度单独滞后） |
| **5. 随机刷新周期** | 平均周期 `2 / 5 / 10 / 20 ms`（刷新间隔在 `0.5 ~ 1.5` 倍周期内均匀波动） |
| **6. FIFO 到达抖动** | 额外延迟在 `0 ~ 1 / 3 / 5 / 10 ms` 内抖动（保持消息顺序，模拟成簇到达） |
| **7. 通道短暂冻结 (Stall)** | `5 ~ 100 ms`（在测量窗内 3 个位置短暂冻结全部字段或仅力矩字段） |
| **8. 接收丢包空窗 (Gap)** | `5 / 20 / 50 / 100 ms`（直接删掉对应时间段的消息行） |
| **9. 力矩一阶低通滤波** | 时间常数 `1 ~ 20 ms`（模拟驱动器电流/力矩滤波带来的幅值衰减与相移） |
| **10. 力矩增益偏差** | `±1 / 2 / 5 / 10 / 20 %`（模拟力矩常数或换算比例误差） |
| **11. 相关块噪声** | `0.02 / 0.05 / 0.1 / 0.2 mNm`（5ms 相关块噪声） |
| **12. 组合退化** | `5ms 共享缓存 + 5ms 力矩低通 + 增益 -5% + 1/3/5ms 力矩滞后` 同时叠加 |

## 🧭 三、如何根据报告选择路线 A 或 B（核心结论）

在本地 SDK Mock 的双频右腕 roll 测试中，163 项退化揭示了非常清晰的规律：

| 典型退化场景 | 路线 A 对自身基线变化 | 路线 B 对自身基线变化 | 结论与启示 |
| :--- | ---: | ---: | :--- |
| **力矩纯时间错位 `±5ms`** | **27.23%**（在 `2ms` 即超 10%） | **0.21%**（`±15ms` 内均未超 10%） | **路线 B 对纯相位/时间错位极其鲁棒**，而路线 A 对几毫秒的通道错位非常敏感。 |
| **力矩一阶低通滤波 `5ms`** | **31.81%**（在 `2ms` 即超 10%） | **5.91%**（在 `8ms` 超 10%） | 路线 B 对低通滤波的容忍度明显高于 A，但滤波过重或跨方向不对称时仍会超 10%。 |
| **共享固定缓存 `5ms`** | 3.96%（正反差 **13.02%**） | 2.74%（正反差 **13.35%**） | 共享缓存对单条曲线变化不大，但会放大正反向差异，**路线 B 不能自动消除缓存影响**。 |
| **力矩增益偏差 `±10%`** | 9.18% | 9.20% | 比例尺度误差对 A 和 B 影响完全相同，必须靠静态重力或已知负载单独标定。 |

### 实机选择原则
1. **当通道时间对齐较好、或降低运动速度后 A 能稳定在 10% 以内时**：优先用**路线 A**（无需复杂多频激励，受未知滤波模型失配影响小）。
2. **当实机存在明显且无法消除的几毫秒力矩通道延迟（导致 A 严重超 10%），而 B 在跨轮复测中稳定时**：采用**路线 B**，但需注意 B 拟合出的等效相位 $\delta$ 只是频域补偿参数，不能直接当成固定硬件延迟写回时间戳（详见 [跨频失配诊断](sdk_roll_frequency_mismatch.md)）。
