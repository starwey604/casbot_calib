# 模型、参数与观测契约

## 机械与驱动

输出侧主模型：

`J*ddq + b*dq + fc*tanh(dq/vs) + k*(q-q0) = g*i + tau_contact`。

`g` 已经是输出侧 Nm/A，不再乘减速比；`J` 是整体等效惯量，不再另加已折算转子惯量。`k` 是外部实验夹具或整体可见柔顺性，不代表要调整集成模组的内部减速器。

| 配置项 | 默认合成值 | 单位／作用 |
| --- | --- | --- |
| `inertia` | 0.08 | kg m²；主要辨识参数 |
| `damping` | 0.12 | Nm s/rad；主要辨识参数 |
| `coulomb` | 0.06 | Nm；主要辨识参数 |
| `spring` | 3.0 | Nm/rad；自由关节设 0 并关闭相应回归列 |
| `spring_zero` | 0 | rad；固定先验 |
| `friction_velocity` | 0.03 | rad/s；固定先验 |
| `gain` | 2.0 | 输出侧 Nm/A；先验或已知附加惯量实验确定 |
| `current_tau` | 0.001 | s；驱动一阶响应时间常数，可设 0 为理想响应 |
| `current_filter_tau` | 0 | s；仅作用于反馈电流，不改变机械实际受力 |
| `torque_limit/current_limit` | 20 / 10 | Nm / A；两者中较严格者生效 |
| `temperature` | 25 | °C；记录字段，冷／热通过两组摩擦值产生 |
| `initial_q/initial_v` | 0 / 0 | rad / rad/s |

未填写 `plant` 字段时采用 `device.default_plant()`。C++ 配置结构本身的理想电流默认值为 0；Python 实验入口显式选择 1 ms。二者都不是厂家数据。

驱动请求为 `kp*(q_ref-q)+kd*(dq_ref-dq)+torque_ff`。混合 PD 使用内部当前真实状态计算；纯力矩模式忽略 PD。请求先限幅，再按一阶响应转为实际电流。无 FOC、电磁或齿轮接触细节。

固定双惯量压力场景使用 `motor_inertia=0.02 kg m²`、`coupling_spring=90 Nm/rad`、`coupling_damping=0.25 Nm s/rad`。电流作用在驱动侧，输出位置仍是唯一默认位置观测。辨识只输出单惯量有效模型，附带独立频带残差。

## 单弦与拨片

弦使用单个横向模态 `m*xdd + c*xd + k*x = -F`；接触通过等效力臂回传关节。拨片和夹持结构合并为接触刚度与阻尼。

定义相对位移 `r=(lever*q+pick_offset)*cos(attack_angle)-x`。当 `|r|<depth`，采用有限宽度光滑势垒：

`U=kc*depth²/(2*pi²)*(1+cos(pi*r/depth))`，

`F=kc*depth/(2*pi)*sin(pi*r/depth)-cc*(1-(r/depth)²)²*rdot`。

区间外接触力为零，边界的力与势能连续；黏性项总耗散。关节得到 `lever*cos(angle)*F`，弦得到 `-F`。这是一种可复现的等效经过／接触／释放代理；不恢复真实拨片形状或弦的多模态声学。`depth` 表示等效接触宽度条件，不是由模型反推的真实几何入弦深度。

| 参数 | F 实验默认值 |
| --- | --- |
| 弦质量、刚度 | 0.010 kg、400 N/m，沿用旧项目代理值 |
| 弦阻尼 | 0.03 Ns/m，合成为持续振动场景；旧项目对照值为 2 Ns/m |
| 接触刚度、阻尼 | 700 N/m、0.2 Ns/m，合成值 |
| 力臂、偏置、角度 | 0.2 m、0 m、0 rad |
| 深度条件 | 1 / 2 / 3 mm |
| 振动初态 | 再激励对照额外加入 0.5 mm 弦位移；过程中不重置弦状态 |

任务映射 `x_pick=0.2*q`；100 mm 匀速段、1 m/s、50 ms 换向，角速度可达 5 rad/s。接触实验与 E 的低速调参实验使用不同任务限制，不套用 E 的 4 rad/s 门槛；各自保留相同的驱动力矩限制。

## 时间、传感器与数据

所有 C++ 时序为 `int64` 纳秒。物理步长默认 50 µs，接触默认 10 µs。事件时间与积分网格分离，积分步会在指令送达或传感器采样前截断，不把 1.35 ms 延迟取整为 1 或 2 ms。

- 指令：`send_ns` 是主机发送时间，延迟／抖动后送达；乱序旧指令不会覆盖更新的指令。
- 反馈：`sample_ns` 是位置／速度采样时刻；`current_sample_ns` 是电流实际采样时刻；`receive_ns` 是反馈送达主机时刻。
- `current_lag_ns` 模拟通道之间的实际观测错位，独立于反馈包的整体传输延迟。
- 时间未知时两个采样字段置 `-1`；接收时间仍保留。负的电流采样时间仅可能出现在已知延迟下的启动历史段，会被预处理丢弃。
- `jitter_ns` 对送达时间施加均匀有界抖动；`drop_probability/repeat_probability` 目前作用于反馈，不模拟指令丢失。重复反馈保留原采样序号并设置状态位。
- `status & 1` 表示该样本请求限幅；`status & 2` 表示重复旧包。输出按接收时刻排序，辨识按采样时刻重排并去重。
- 温度、电流和位置使用 SI 单位；`estimated_torque=g*current` 标记为派生值，永远不追加为第二组独立观测。
- 当前虚拟设备两种时钟共享已知原点；硬件适配必须记录时钟域、同步方式及映射，不能直接假定 DC 时钟等于主机时钟。

NPZ 存数值数组，JSON 存配置、单位、来源、时序声明、版本和 SHA256。真值在独立 `evaluation_truth.npz`，包含实际加速度、接触力、弦状态与机械能。`identify` 不读真值或含有真值的 metadata，只读 observations 和显式 Prior。

双编码器存在不等于 SDK 同时开放两侧数据。默认能力没有独立力矩或外部力传感器，也不预设内部 PI 可调。后续千分表作为可选位移列接入；必须结合已知负载才讨论刚度，不能把位移计当作力传感器。
