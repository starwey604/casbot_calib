# 左腕 roll 残差定位：静摩擦反力进入了惯量频点

**主因是换向时的停滞反力没有进入点值摩擦预测，不是 40 阶截频少算了惯量。** 左腕 roll 在 2.833 Hz 的同相残差为 +5.197 mNm。把原始样本按实际速度分区、再对各区残差投影后，近零速区贡献 +5.774 mNm，持续运动区反而抵消 −0.612 mNm。

## 分区在滤波前做，才能定位残差来自哪里

沿用只补 yaw 的 R2 完整训练解（1e-4），冻结刚体、摩擦参数和重力。四条记录各取原分析相同的最后两个完整稳态周期（4 kHz）。在原始采样位置和速度计算 Pinocchio 质量矩阵、重力及速度项；加速度分别从位置二阶导和速度一阶导得到，均比较 40、80、120、240 阶（最高 40 Hz）。摩擦仍用原点值特征，按原始速度计算。各速度区间各自投影到轴主频，三项的复数和逐条重构总残差。

| roll 原始速度区间 | 时间占比 | 2.833 Hz 加速度同相贡献 |
| --- | ---: | ---: |
| ≤0.002 rad/s | 9.55% | **+5.774 mNm** |
| 0.002–0.02 rad/s | 4.05% | +0.035 mNm |
| ≥0.02 rad/s | 86.40% | **−0.612 mNm** |
| 合计 | 100% | **+5.197 mNm** |

表为四条记录均值，使用速度导数、240 阶。两种求导和四档带宽下，roll 主频总残差均为约 **5.228 mNm RMS**；对比原 40 阶，逐条最大差低于 **0.001 mNm**。提高带宽不会消掉这个频点的误差。上一轮报告的「26%」是在**已滤波残差**上按主频速度分区，滤波已把短时停滞的贡献摊开；它不能定位原始误差发生处。

## 停滞反力足以解释主要量级，持续运动仍有次要差异

每条 roll 记录有 **68 个停滞段**，每段约 **15–17.75 ms**，约占 **9.4%** 的采样时间。按实测速度为零且位置基本不变选段，去掉两端各一个样本。冻结模型、令停滞轴加速度为零后，扣除重力、速度项及其他轴惯量贡献，得到维持该停滞所需的反力。与冻结起动摩擦上限 **69.57 mNm** 比较，**99.36–99.57%** 的段内样本在允许区间；仅这些段内反力在 roll 主频就贡献约 **+5.86 mNm** 的加速度同相力矩。点值模型的 `sign(dq)` 在速度为零时给零，无法表示这段非零反力；原生 Mock 则通过约束求解保留静摩擦反力。

持续运动也不是零误差：在相同有符号速度小区间内比较正、负加速度，冻结模型的等效惯量残差为 **−0.000426 至 −0.000445 kg·m²**。这是用于辨别误差方向的条件对照；它不能区分真正的惯量差与随运动历史变化的摩擦。不能把去掉停滞贡献理解成 R2 已能通过。

## 下一步：先用现有数据做持续运动重分析

保持只补 yaw 的基线、原有数据和权重，单独对这四条窄幅记录做一次诊断性重分析：在**原始时间轴**标记停滞与转场，不给零速样本指定唯一力矩；持续运动段的观测与回归量使用同一时间支持，避免先对完整周期投影再删低速行。用同一 128 个评估点比较完整／删 c02 的惯量差，不替换正式验收路径。若持续运动对照仍不能解释残余，再考虑同构型、同频率、正反非换向 roll 单轴对照。当前不增加采集、不改 10% 门槛。
