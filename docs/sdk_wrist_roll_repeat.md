## A／B 未扰动结果

跨会话差始终为 `abs(J新−J旧)/max(abs(J旧),1e-6)`，同方向分别比较，不先平均正反：

| 路线 | 方向 | 原 J kg·m² | 新 J kg·m² | 跨会话差 |
|---|---|---:|---:|---:|
| A：直接同带宽拟合 | 负向 | 0.00027849 | 0.00027422 | **1.531%** |
| A | 正向 | 0.00025117 | 0.00026633 | **6.037%** |
| B：多频 J／b／等效相位 | 负向 | 0.00028963 | 0.00026848 | **7.302%** |
| B | 正向 | 0.00026368 | 0.00025826 | **2.056%** |

| 比较 | A | B |
|---|---:|---:|
| 原会话正反方向差 | 9.810% | 8.958% |
| 新会话正反方向差 | **2.879%** | **3.805%** |
| 跨会话含跨方向的最差差异（旧记录作分母） | **9.180%** | **10.829%** |

B 的最后一项来自「旧负向 → 新正向」。同方向复测均在 10% 内，不等于任意方向／会话组合都在 10% 内。JSON 另外保留四条全配对、较小 J 作分母的对称差异；那是补充诊断，不能替换原方向差定义。以上均为局部单轴比较，未执行原 128 点的完整刚体 R2。

B 的等效相位负向由 −1.301ms 变为 +0.607ms，正向由 −1.105ms 变为 +0.820ms，整体相差约 **1.9ms**。诊断粘性项负向从 0.008160 变为 0.010271Nm·s/rad，正向从 0.011260 变为 0.010713Nm·s/rad。它们没有写回观测时间或 H3 候选；本轮不能把某一次相位拟合固化成设备延迟补偿。

完整扫描也保留大缺口／长缓存造成的数值不稳定，不截掉巨大误差或改写为通过。新会话 652 个路线结果中，647 个可用、5 个在强退化下不可用，原因见 JSON／CSV。采集流程不受这些诊断锁定。

## 使用评估器复现跨会话比较

```bash
bash scripts/humble/container.sh casbot-fieldwork sensitivity \
  --source artifacts/sdk_wrist_roll_repeat_v1 \
  --reference-assessment artifacts/sdk_feedback_sensitivity_v1 \
  --output artifacts/sdk_wrist_roll_repeat_comparison_new
```

`--reference-assessment` 是旧评估目录，不是原始采集目录。评估器只重分析新输入，按相同波形、处理、先验和有效模型／尺度／PD 绑定寻找旧会话；不同配方的单频 pitch／roll 会明确列为不匹配，而不会混进跨会话统计。原无此参数的调用保持原功能。
