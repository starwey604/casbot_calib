# 动力学 P0 R2：固定坐标与算子稳定性

2026-10-28。对应[P0计划](staged_dynamics_p0_plan.md)的R2；复用[R1](staged_dynamics_p0_r1.md)已封存数据，无新采集。只读train与前序开发参考，不打开selection或test观测。通过R2表示候选具备本协议的稳定性资格，不是选参、惯量收益或实机验收。

## 入口

```bash
bash scripts/humble/container.sh casbot-calib staged-identify \
  artifacts/staged_p0_r1_release --through stability \
  --output artifacts/my_p0_r2

bash scripts/humble/container.sh casbot-calib staged-verify \
  artifacts/staged_p0_r1_release --stability-analysis artifacts/my_p0_r2 \
  --output artifacts/my_p0_r2_checked
```

目录必须不存在；同一实现和输入下，中断的R2可加`--resume`继续。固定协议、坐标、探针、先验、缓存、每个变体和最终交付均有摘要；更换实现后使用新分析目录，不能回写旧记录。恢复已完成变体不重新拟合；求解失败或删组失秩保留为失败，不择优删除。完整R1/旧schema 1入口保持原行为。

## 固定坐标与求解

`fit_rigid`新增可选`fixed_scales`、`regularization_metric`。未指定时保持旧算法，包括原有数据零空间正则项。R2显式传入完整168维尺度：140个刚体参数取名义模型尺度，28个运动摩擦参数取冻结前序尺度，整个分析中不随先验/删组/修正结果改变。

完整正则化度量固定为该坐标中的单位阵，使用`ridge × metric`，不再混入随删组变化的零空间惩罚。名义模型是固定正则化中心；四个先验变体仅改变中心，不改变变量尺度、数据、边界或等式。初次固定摩擦解和联合解都使用该声明的中心，联合解不以初次结果作为新的正则化中心。

目标仍为原有四次鲁棒IRLS、Clarabel伪惯性PSD和QR压缩残差。所有候选保持同一重力等式、静摩擦和±5%运动摩擦边界。完整train的轨迹/轴权重只计算一次，删组只删对应行，不重新归一化，避免同时改变权重与正则化强度的解释。

公共基来自完整train、冻结尺度和重力等式零空间中的直接SVD，使用相对`1e-7`与绝对`1e-12`门槛。删组使用完整train的同一绝对截断值，报告秩损失、主角、投影差及奇异值；参数变化投影始终用公共基。基是在固定行权重之后、候选专属IRLS权重之前定义的，不是统计置信区间。

## 探针与分析矩阵

`operator_probe_set.npz/json`在拟合前冻结128组q/dq/ddq，来源是七个已通过参考碰撞门禁的计划中心和双臂周期参考；所有轴的绝对速度大于0.02rad/s，避开静摩擦转换。它们是静态算子查询，不执行运动、不读取test观测，也不能替代独立预测或证明域外有效。

每个ridge（`1e-5/1e-4/1e-3`）执行完整train、删三个中心、删两个批次、四个物理合法先验，共30个联合解。完整train另保留三个固定摩擦初次解，共33次刚体拟合调用。先验由固定种子生成：质量±10%、COM每分量±1mm、COM惯量整体±10%；几何、工具、增益与已知执行器惯量不变，不读取Mock真值。

删组/先验与同ridge完整train比较；正则化路径另统一与预声明的`1e-4`完整train参考解比较，不能各解只与自己比较。候选必须同时满足两类比较和全部前序/数据门禁。

## 前序门禁与物理边界

`staged_stability_prior.py`缓存Pinocchio重力回归量。运动摩擦与原标量路径共用控制周期平均、沿时间轴的Savitzky–Golay和实际位置配对投影；每条前序扫描都与原标量原生重力路径核对，最大允许差`1e-10`。这使30个变体能精确复用开发门禁，无需反复读取/处理GB级原始数据，也不把重力冻结当作可以省略复核的理由。

每个候选/变体重验原有重力、运动摩擦、起动重力变化门禁，并保留完整train及删去组的预测诊断。质量矩阵和逆动力学全部来自同一Pinocchio物理模型，已知armature只计一次。

固定探针上的合成门槛：质量矩阵相对F范数最大5%；逐轴对角项最大10%（分母下限`1e-6 kg m²`）；同q/dq/ddq逐轴逆动力学差异RMS最大2%（力矩RMS分母下限0.2Nm）。报告伪惯性特征值、声明长度下的PSD边界距离和辅助参数边界命中；单个连杆参数变化或边界命中不单独判失败。不可观测代表可以变化，算子必须稳定。

## 输出与独立复核

- `analysis_protocol.json`：拟合前冻结的输入、尺度、度量、先验、探针、规则与源码摘要。
- `training_setup.json`、`comparison_basis.npz`：公共基、谱、权重、缓存摘要与刚体/摩擦模式占比。
- `variants/*`：每次解、物理候选、求解状态、秩、算子/参数变化、前序和train预测门禁；失败也保留。
- `regularization_path.json`、`group_sensitivity.json`、`prior_sensitivity.json`、`operator_stability.json`、CSV与中文PNG。
- 独立`staged-verify --stability-analysis`校验全部封存、30个变体的完整性，再从候选参数通过Pinocchio重算全部保存的M/逆动力学；另核对固定参考的正则化路径，输出最终稳定性资格。

资格证据只绑定train清单；R3完成归因及selection预测后才能选择、冻结候选。`stability_qualified=true`不等于`publishable`或`p0_acceptance_passed`。R2不修改PD、不运行最终四组控制，不使用控制效果反向选择动力学候选。
