双频提供了单频恰好拟合时没有的跨频余量：声明 b=0.01 的模型无法像自由 b 模型一样同时解释两个频点。放开一个参数也会降低拟合残差，因此这不是“真实摩擦已变为上述数值”的结论。下一批必须核对 J、b 和等效相位是否可重复，而不是只看当前残差。

主模型的两方向等效相位较接近，但各频点仍有差异；当前数据不能把缓存、通道滤波和模型失配唯一归为一个物理延迟。没有据此作时移补偿或改采样资格。
