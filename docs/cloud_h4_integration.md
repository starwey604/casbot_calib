# 云端 H4 更新接入

已将 `origin/main` 的 5 个提交接入本机 main，当前基线 `d0ffe42`。保留本地腕部辨识、S4 分阶段入口和测试文档；README 同时保留云端现场工具包与本地测试／回填入口。

## 新接口按云端语义使用

- 现场 H1–H4 不再以窗口质量、覆盖／经验样本数、50ms 缺口、速度一致性、激励 RMS、拟合残差、前序残差或控制事后筛选锁批次；不自动质量重采。
- 通用速度默认 1.5rad/s；关节／模式接收超时为 2秒／3秒。反馈位置越界只记录，现场跟踪和正常结束回位验收已删除；末帧后仍需成功退出模式。
- 数据绑定、参考／命令碰撞、模式／通信／SDK 故障仍保留；数学秩、有限数值和 PSD 不是经验门槛。确实缺数值输入时报告不可用／未执行，不造参数或拿 prior 冒充 identified。
- `passed`、`available`、`collection_complete` 分别表示不同结果，不再用旧的“质量 passed”控制下一阶段。S3／S4／P0 正式规则未改，10% 仍是研究结果评价数值。

## 本地调用已配套适配

1. 低频 SDK 腕部探索改用 H4 新的 `available` 预测指标，并使用全部相位行，不再读取已删除的 `moving` 筛选掩码。新分析报告为 v2；旧 v1 报告原样保留。独立复核可用 `--analysis 新分析目录` 指定当前口径，报告会核对口径版本。
2. 新双频写入器生成 `casbot_sdk_wrist_roll_dual_v2`，不再封存旧经验质量 limit；旧 JSON v1 只为原记录重放保留原规则。具体见[双频协议](sdk_wrist_roll_dual_protocol.md)。
3. 单频／双频探针封存重规划配方：只在原生已证明未请求模式、零指令、无故障时，复用公共起点重规划路径；保留固定姿态、波形、PD、域号及绑定，重新检查完整路径。不是故障恢复。
4. 相关分析器及 CSV 复核器通过 `resolve_field_capture` 使用实际执行计划／采集，避免把重规划后的观测套进原起点计划。
5. 现场测试手册已删除失效的人工方向 review 命令，并同步批次报告和质量只报告语义。
