# 右腕 roll：用双频探针区分惯量、摩擦与等效相位

**推荐最小补采设计为 c00 右腕 roll 正反各一条，每条同时含 2.5Hz 和 10Hz。** 原来的两条 5Hz 记录继续独立保留。此次只完成离线分析、解析读出验证和参考规划，没有新增采集。

单频冻结摩擦在理想模型中可以分开惯量与相位，但现有两条记录给出的方向惯量差为 **24.08%**，不能据此修正原训练结果。双频在“尺度已定、冻结重力、纯相位”的条件下增加了分离信息；当前误差预算仍不能保证通过 10%。

- 离线比较：`artifacts/sdk_wrist_roll_frequency_design_v3`。
- 独立复核、原生重力解析读出及推荐清单：`artifacts/sdk_wrist_roll_frequency_review_v1`。

## 现有 5Hz 数据：能求出相位，不等于稳定辨识

复用已独立复核的公开反馈问题：原 30Hz 共同处理、原 1.6 秒有效窗口、相同时间行和权重。位置、速度、力矩均以回调可用时刻解释，不构造采样时刻。

对实际加速度、速度、nominal 重力、转子与声明摩擦共同提取复数频点，采用：

```text
Y_f = exp(i·ω·δ) · [J·A_f + b·V_f + G_f + R_f + Fc_f]
```

`δ>0` 表示 effort 向前评估，与原时移诊断同号。它是模型的等效相位参数，不是 SDK 真实延迟；不能填回采样时间字段。重力使用实际公开 q 上的 Pinocchio 计算，不从命令前馈取观测。

先固定声明的 b=0.01Nm·s/rad 及其余摩擦项，以幅值解正惯量，再由复数比值求相位：

| 现有记录 | 惯量（kg·m²） | 等效相位折算（ms） |
| --- | ---: | ---: |
| c00 roll 负向 | 0.00030176 | −3.729 |
| c00 roll 正向 | 0.00022910 | +4.812 |

两方向惯量差为 **24.08%**（仍按负向惯量作分母）；此前零相位、自由局部粘性项诊断为 4.51%。单频模型只有两个实数观测，冻结 b 后恰好求两个未知量 J／δ，没有多余约束检查模型是否合适。

将声明摩擦系数分别改为 0.8／1.0／1.2 倍，只作敏感性诊断：负向 J 为 0.00035972／0.00030176／0.00020857，正向为 0.00030221／0.00022910／0.00004262kg·m²。不同的摩擦假设仍可由 J 和相位补偿而精确匹配该单频。**现有记录不足以把这组补偿关系选成可信的时序校正。**

人为对整个 effort 复数频点施加 ±5ms 相位时，正确冻结摩擦的单频幅值解保持 J 不变，相位相应变化。这验证的是方法的理想性质，不能消除上表的实际方向分歧。

## 双频增加了什么信息

不再把粘性系数完全可信作为唯一支撑，改为同时估计局部 J、诊断用 b 和每条记录的等效 δ：

- 单频给出 2 个实数观测，3 个未知量，秩为 **2/3**；重复同频不会补齐这一方向。
- 同一条双频记录给出 4 个实数观测，局部秩为 **3/3**，还留有 1 个实数约束检查跨频率模型。
- 也可新增独立 2.5Hz 记录，与原 5Hz 记录只比较幅值：两个频率能在单位尺度、已知重力、同一 J/b 条件下求出 J/b，**不要求两个记录相位相同**。但若给每个频率各一个自由相位，模型刚好解释四个实数，没有同一条记录内的跨频自检。

拟合 b 仅用于诊断惯量／相位的混叠；不更新 H3 摩擦候选，不改原训练权重或已有候选。

### 同一个误差预算下的方案比较

从现有 1.6 秒窗口依次删去四个 0.4 秒块，保留原行权重、不用跨缺口曝光权重填补数据。5Hz 力矩复数系数相对完整窗口的最大变化为 **0.05116mNm**（复幅值，不是 RMS）。将此值假设为每个新频点的误差半径，得到下表。

这是离线设计的条件预算；新频点尚未采到，表中不是置信区间，也不是原 R2 删组结果。

| 方案 | J/b/相位的信息 | 条件线性最坏 J 变化 |
| --- | --- | ---: |
| 再采相同 5Hz | 仍缺一个方向 | 无有限唯一解 |
| 另采 2.5Hz，与旧 5Hz 比幅值 | 幅值可解 J/b，无跨频模型余量 | 17.71% |
| 同条 2.5+7.5Hz，保持原速度／jerk预算 | 秩 3/3 | 15.88% |
| 同条 2.5+7.5Hz，幅值 0.005／0.0015rad | 秩 3/3 | 12.07% |
| **同条 2.5+10Hz，幅值 0.0075／0.00068rad** | **秩 3/3** | **10.26%** |
| 同条 2.5+5+7.5Hz，幅值 0.003／0.001／0.001rad | 更多约束，但该幅值分配的信号较弱 | 20.83% |

所比较的 10Hz 方案比 7.5Hz 方案有更大的非换向速度余量、较小的条件惯量敏感性。三频并非无用，但当前这组包络内的分配未体现收益，不值得在最小试验中加入第三个频点。

对推荐方案再在两个复数误差圆上各取 8 个相位，共 64 组有限幅值扰动，非线性重估的最大 J 变化为 **10.36%**。因此本轮选的是最小的**信息验证补采**，不是已经预言能过 10% 的正式训练方案；也不因接近门槛而改数值或自动加批次。

## 推荐清单：两条，每条两个频率

单条双频已提供局部分离所需信息；两条是保留原正反方向一致性核对的最小方案。

| 项目 | 固定设计 |
| --- | --- |
| 轴／中心 | c00 右腕 roll（索引 13）；左右腕 pitch／roll 仍为 +0.20／+0.30rad |
| 新记录数 | 负向 1 条、正向 1 条，无其它姿态／批次扩张 |
| 每条测量窗 | 2 秒，首尾各去 0.2 秒用于主频响分析 |
| 正弦位置幅值 | 2.5Hz：**0.0075rad**；10Hz：**0.00068rad**，两项初相均为 0 |
| 单向基础速度 | **0.18rad/s**，方向符号同时作用于基础运动与两项正弦 |
| 主命令／缓存 | 500Hz 位置流；5ms 共享缓存标准，1000Hz 发布夹具 |
| 其余轴／补偿 | 其余 13 轴保持；原合成 PD 与 nominal 重力前馈，不加摩擦前馈 |

测量段采用 `q_j(t)=q_start + sign·[0.18t + 0.0075sin(2π·2.5t) + 0.00068sin(2π·10t)]`。保持原净位移 0.36rad；通过现有 C3 探针原语的线性叠加生成完整进场、渐入、制动、回位，不另写机械内核。

完整多项式的连续界为：速度 **0.34054rad/s**、加速度 **4.41978rad/s²**、jerk **197.766rad/s³**，仍在原 **1／8／200** 专用包络内；测量段有符号速度下界 **0.04913rad/s**，高于原 0.02。正反两个完整参考及其 500Hz 命令折线均通过原 **10mm** 碰撞检查。这些是冻结起点下的规划证据，未来采集仍从当次姿态快照重建路径。

规划用惯量取当前两个零相位局部诊断的均值 0.00026880kg·m²，非私有 plant 真值；两频点的假设惯量力矩 RMS 为 **0.352／0.510mNm**。实际伺服在 10Hz 的跟踪、保持轴及力矩信号须在未来两条记录中核对。

## 哪些结论已验证，哪些由新记录检验

**纯相位模型可分离。** 两频点解析模型中，粘性项 0.8／1.0／1.2 倍、相对相位 −5／0／+5ms 的九组无噪声情形均恢复 J。另以同一原生 Pinocchio 重力、完整 C3 参考、5ms 共享缓存构造正反方向共六组理想读出；共同处理后的最大 J 误差为 **0.00685%**，等效相位误差最大 **1.66µs**。这里只构造读出数组，没有推进 Mock 或采集新数据。

**未知滤波／尺度仍可能伪装成相位或惯量。** 对推荐方案额外施加 5ms 一阶 effort 低通，再仅拟合纯相位，J 偏差约 **5.02%**；施加 ±15% effort 增益，J 偏差约 **13.68%**，但复数残差仅约 **0.0139mNm**。小残差不足以证明尺度或纯延迟假设正确。

未来两条先对比零相位、冻结 b 频响和自由 b 频响；同时检查实际速度、保持轴、两个频点、分窗口稳定性、方向一致性及跨频残差。等效相位只留在新的探索模型里，不回写原观测时间，也不靠选择一个时移来把旧 R2 改成通过。
