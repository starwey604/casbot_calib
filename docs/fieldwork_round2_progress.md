## 2026-11-12启动上下文修复

用户在同时含`DISPLAY`/`WAYLAND_DISPLAY`的桌面启动时，在`glVertexAttribPointer`报“Attempt to retrieve context when no valid context”。已在私有Xvfb复现：GLFW为X11原生GLX，而PyOpenGL因Wayland变量选中EGL；即使软件渲染仍会失败。前面的iris驱动警告不是该上下文错配的原因。

`fieldwork_window.bind_window_opengl()`改在窗口创建/设为当前之后、导入OpenGL绘图后端之前，按GLFW实际平台和context API绑定。环境覆盖只包围PyOpenGL平台导入，随后还原，避免GLX选择泄漏到MuJoCo/EGL模型和视频子进程。已预加载错误平台的嵌入式调用会给出新进程启动提示。

18项窗口/显示回归通过；保留双桌面变量的标准和软件渲染GUI各启动8帧、模型子进程输出、关闭后自有Mock正常退出通过。另验证X11显式EGL上下文可正确绑定；未截图或查看实际画面。代码为Python改动，无需重编C++。证据：`artifacts/fieldwork_context_fix_v1/verification.json`。
