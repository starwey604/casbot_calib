# 右腕 pitch：删 c02 丢掉了正 roll 下的 pitch 约束

**缺的不是更多加速度，而是右腕 roll 为正时，用 pitch 力矩约束 pitch 惯量随 roll 的变化。** `train_c02` 是唯一在较宽正 roll 范围提供这类观测的中心。删掉它后，原最坏点虽然在**负** roll（−0.686 rad），但拟合对该点的等效惯量由 0.84371 增至 0.92909 ×10⁻³ kg·m²，变化 **+10.120%**。

## 为什么正 roll 的数据影响负 roll 的结果

用 Pinocchio 在同一姿态下的单位 pitch 加速度与零加速度回归量之差，得到右腕 pitch 对角惯量的线性映射。只改变下游右腕 roll，可在原 128 个算子查询姿态重构整条映射，最大系数误差约 $1.2\times10^{-15}$。重算的删组惯量差也与原生质量矩阵一致。右腕对角惯量不能据此归给某个单独连杆参数。

固定 1e-4，删 c02 前后的惯量差可分解成常数、cos(2·roll)、sin(2·roll) 三项；一倍角项在数值精度内为零。最坏点的三项贡献分别为 **+48.84、−16.53、+53.07 ×10⁻⁶ kg·m²**。sin(2·roll) 项跨正负角翻转，恰是删除 c02 后最难约束的一项（线性误差放大 **2.46×**）。缺失正 roll 信息会改变整条姿态曲线，不只影响正 roll 处的预测。

| 中心 | 周期记录中参与右 pitch 力矩回归的实测 roll 范围 | 同批 pitch 加速度 RMS |
| --- | ---: | ---: |
| c00 | −0.699 至 +0.023 rad | 1.42–1.51 rad/s² |
| c01 | −0.778 至 −0.040 rad | 1.36–1.52 rad/s² |
| c02 | **+0.019 至 +0.616 rad** | **1.40–1.44 rad/s²** |

c02 的加速度并不更大，区别在于有足够跨度的正 roll；其右 yaw 单轴探针也都在 roll 约 +0.30 rad 的姿态。

## 哪些现有观测真正约束了该方向

只用已封存 train，保持原行权重、尺度和重力等式。在共同可观测空间内，以原最坏点的 pitch 等效惯量为目标，先删除 c02，再逐块恢复 c02 的观测行。该方向在完整数据中约 **78%** 的加权响应能量来自 c02。该中心内部：

| 恢复哪些 c02 行 | 占 c02 对该弱方向的响应能量 | 线性误差放大，相对完整 train |
| --- | ---: | ---: |
| 不恢复 | — | 1.523× |
| 只恢复周期记录的右 pitch 力矩行 | **59.0%** | **1.118×** |
| 只恢复右 yaw 单轴探针 | 32.4% | 1.350× |
| 恢复全部周期记录 | 67.6% | 1.089× |
| 恢复全部 c02 | 100% | 1.000× |

这里的倍数是固定重力约束与权重下，测量误差映射到该惯量目标的线性敏感度；各块恢复后的倍数不能相加，也不能换算为真实补采后的 R2 百分比。共同空间已覆盖此惯量目标；问题是约束变弱，而不是这个对角项完全不可观测。

**下一步优先设计在 c00/c01 补正 roll 保持姿态下的右 pitch 激励**，并用负 roll 的同类参考作对照。首选正反非换向方案：直接补右 pitch 力矩约束，又可避开左腕诊断暴露的停滞反力污染。不优先加大现有同姿态幅值，也不只补 yaw 探针。本轮没有规划或采集新轨迹，没有重拟合或改 10% 门槛。
