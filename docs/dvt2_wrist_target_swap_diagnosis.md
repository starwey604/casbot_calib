# 分频记录为何恶化删构型：力矩目标反事实

**先查左腕 roll 的同相力矩残差，不继续追加同类分频记录。** 在不改轨迹、权重或物理约束的情况下，把 4 条分频记录的力矩目标换成只补 yaw 的完整训练解预测，删 `train_c02` 的最差对角差从 **19.820% 降到 10.204%**。因此，仅靠增加这些轨迹的信息不会造成观察到的恶化；新增力矩与基准模型的差异是本次恶化的主要驱动。这个实验没有验证基准力矩正确。

## 固定原 R2 比较，只改新增目标

固定正则化 1e-4、重力等式、摩擦边界、物理约束、尺度、训练权重和同一组 128 个算子评估点。复用已有 4 个完整／删组解，只做两次新拟合（反事实的完整训练和删 `train_c02`），不重跑完整 R2。四条记录的实测 q/dq/位置解析加速度和特征保留；在求解器坐标中，只替换它们的 **11,720 个加权运动行**的目标为基准预测，其余 **215,590 行**原样使用。

| 数据／目标 | 删 `train_c02` 的最差对角差 | 最差轴 | 在原实测最坏点的 roll 对角差 |
| --- | ---: | --- | ---: |
| 只补 yaw（已有解） | 15.300% | 左腕 pitch | +10.968% |
| 加四条实测分频（已有解） | 19.820% | 左腕 roll | +19.820% |
| 加同样轨迹、替换四条力矩目标 | 10.204% | 左腕 yaw | +10.150% |

在实测最坏点，完整／删组解的 roll 对角项由 **0.7721／0.9251 ×10⁻³ kg·m²** 变为反事实的 **0.6343／0.6987 ×10⁻³ kg·m²**。两边都移动，删组移动更大。**10.204% 仍高于 10%**，而且替换力矩的记录只能做归因，不能作验收输入。

## 残差定位：roll 最强，不能用统一时间平移解释

使用原 40 阶相位处理，定义残差为实测减预测。下表是只补 yaw 的完整解在四条分频记录各自激励频点的残差；同相分量以对应轴的实测位置解析加速度为相位参考。

| 轴 | 频率 | 残差 RMS | 加速度同相分量均值 | 基准刚体惯性项 RMS 均值 |
| --- | ---: | ---: | ---: | ---: |
| yaw | 1.167 Hz | 1.634 mNm | +1.631 mNm | 1.601 mNm |
| pitch | 1.833 Hz | 1.912 mNm | +1.912 mNm | 1.619 mNm |
| roll | 2.833 Hz | **5.228 mNm** | **+5.197 mNm** | **1.132 mNm** |

roll 残差在两构型、两批间都为 5.224–5.231 mNm，重拟合后完整解仍有 4.983 mNm。残差方向接近惯性加速度，量级又超过基准 roll 刚体惯性项约 4.6 倍，足以在拟合中牵动小惯量。

- **采样钟不支持统一错位解释。** Mock 把 q、dq、电流放在同一次采样；四条记录的接收延迟均为 0.700 ms。原始 dq 与由 q 求导在各自主频的等效相位差小于 0.0002 ms。若硬把残差全解释成摩擦相位移动，三轴所需等效超前分别为约 4.8–5.2、4.0、7.4 ms，并不是一个共同时间偏移。Mock 的 1 ms 电流响应是动态状态，不等于采样通道错位。
- **在这些频点，模型算出的跨轴项太小。** 其他轴加速度贡献与速度耦合项的 RMS 分别不到 0.00005 mNm 和 0.0007 mNm，不能单独解释观测的 mNm 级差异。
- **值得查换向摩擦，但不能把 roll 残差全归到零速。** 以主频速度不超过峰值 20% 为换向邻域，约占一周期 13% 的相位；它贡献了 yaw 约 66–70%、pitch 约 58%、roll 约 26% 的加速度同相残差。roll 的大部分同相残差在邻域以外；40 阶投影会把局部差异摊到其它相位。

下一步先用现有记录做**宽频、速度分区的力矩平衡诊断**：冻结同一刚体候选，在原始相位上比较换向前后与持续运动段，核对当前摩擦特征和截频是否把力矩误差投到惯量列。若 roll 残差不能由这些差异解释，再设计同构型的非换向 roll 单轴对照；不预先改 10% 门槛，也不读取正式测试观测。

## 复现

```bash
base=artifacts/dvt2_004_wrist_supplement_local_v1
new=artifacts/dvt2_004_wrist_three_axis_integration_v1
out="$new/target_swap_recheck"
bash scripts/humble/container.sh python scripts/humble/diagnose_wrist_periodic_counterfactual.py \
  "$base/development" "$base/r2" "$new/development" "$new/r2" "$out"
bash scripts/humble/container.sh python scripts/humble/inspect_wrist_periodic_balance.py \
  "$base/development" "$base/r2" "$new/development" "$out/balance.json"
```

本次结果位于 `target_swap_v1/`：`report.json` 保存反事实比较及两个新解的对照，`frequency_residuals.csv` 保存逐记录、轴、频点的复数残差，`balance.json` 保存时序、跨轴与换向检查。仅使用 train，没有新采集，没有读取选参、正式测试或 plant 真值。

[宽频与原始速度分区复核](dvt2_wrist_wideband_balance.md)已定位主因：roll 停滞段的静摩擦反力主要贡献了加速度同相残差，40 阶截频改变的是残差在相位上的分布，不是主频残差总量。
