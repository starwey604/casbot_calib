# 静态现场扫描预设

本轮提供**离线参考规划**：从具名关节扫描与组合姿态中筛选候选，使用Pinocchio重力回归量选点，使用Coal检查完整进退路径，冻结正反接近的训练/验证参考。默认配置为[static_field_nominal.yaml](../configs/static_field_nominal.yaml)，入口为`plan-static-field`与`verify-static-field`。

它不订阅或下发ROS消息、不切换模式、不采集反馈，也不拟合质量/质心。生成的测量窗口是采集计划，不是假造的观测；现场S3/S4观测资格、设备限制和执行前提继续独立检查。当前模型为新CASBOT nominal固定腰部双臂，夹具仍为未测量的代理盒体，不是实机几何验收。

## 扫描规则

- 维持完整14轴双臂、躯干和夹具的碰撞/动力学模型，每次仅一臂运动，另一臂保持配置基准角。所有角度明确按名称映射，单位为rad；扫描表中的deg是**相对基准角的偏移**，不套用其他六轴机械臂的绝对姿态。
- 每臂7个轴分别产生`[-75,-45,-20,0,20,45,75]`度候选；具名的第2至6轴产生`[-30,0,30]`度的五轴组合。每臂49+243=292条原始请求，去重后285个姿态，两臂共570个；中性姿态保留为基准记录，不分配给训练/验证。不会截断、缩小或偷偷改写碰撞/超限角度。
- 默认基准为`[0,0.85,0,-0.9,0,0,0, 0,-0.85,0,-0.9,0,0,0]`rad。肩部更外展是为了在nominal模型中保留正反扫描空间，属于合成规划选择，不能代替真实起始姿态观测、方向/机械零位确认或从实机当前姿态到基准的路径检查。
- 每个姿态从正反两个方向接近。单轴点仅沿该轴偏置0.025rad，组合点沿所列组合轴偏置；两条参考均完整返回同一个基准姿态。正反接近用于保留静摩擦/迟滞不确定度，不能保证实机静摩擦完全抵消。

## 筛选与划分

先检查目标和两个接近点的nominal限位及碰撞余量；这只是端点筛选。选中的每一对参考还必须通过现有`Motion`、Bernstein导数界和Coal连续参考门禁，覆盖初始保持、接近、最后接近、稳定、测量、返回和最终保持。任一方向失败，整对淘汰并尝试其他候选；未选中的端点合格姿态明确标为尚无连续路径证书。当前证书覆盖声明的参考，不证明主机插值/跟踪误差包络、物理停止或未观测实机路径。

每臂先保留7轴各正反方向的单轴诊断，优先选择仍合格的较大偏移；缺少任何方向时报告不通过。随后在不重合的候选中选8个验证姿态，再补足24个训练姿态。两组均以参考回归量的D-optimal信息增益选点，验证候选的同分顺序由固定种子确定；选点不读取测量力矩、Mock真值或已消耗的P0正式test。

Pinocchio在`dq=ddq=0`计算标准140列刚体回归量，使用既有`parameter_scales`固定物理尺度并做SVD。每臂选点只使用该臂7个力矩方程，避免把另一臂固定不动的方程计作扫描收益。训练与验证必须分别覆盖端点候选池的可观测方向；默认每臂秩14。静态数据只约束质量/一阶矩的组合，不辨识转动惯量，也不保证每个连杆的质量/质心唯一。

只用五轴组合的验证集曾得到每臂秩13，缺失腕部roll的方向；当前验证池同时包含剩余单轴点，并增加同秩检查。它仍只是几何/重力信息覆盖，不是独立实测预测验收。

## 时间安排与输出

每条参考顺序如下：

| 环节 | 默认时长 |
| --- | --- |
| 基准初始保持 | 0.5s |
| 基准到接近点 | 至少2s |
| 接近点到目标 | 至少1s |
| 目标稳定等待 | 2s |
| 静态测量窗口 | 1s |
| 返回基准 | 至少2s |
| 最终保持 | 0.5s |

运动段按连续速度/加速度/jerk界自动延长，默认规划包络为0.75rad/s、1.5rad/s²、10rad/s³；这是合成规划值，不是厂家额定能力。默认客户端参考周期2ms（500Hz），不意味着设备采样500Hz。轨迹NPZ保存连续多项式而非伪造的反馈样本，`command_period_ns`保留供后续适配。

```bash
bash scripts/humble/container.sh casbot-calib plan-static-field \
  --config configs/static_field_nominal.yaml \
  --output artifacts/my_static_field
bash scripts/humble/container.sh casbot-calib verify-static-field \
  artifacts/my_static_field --output artifacts/my_static_field_review
```

输出目录必须不存在，复核输出须位于冻结规划包之外；规划失败也保留候选、淘汰原因及报告，不能覆盖后重写为通过。

| 文件 | 内容 |
| --- | --- |
| `config.json`、`scene.json` | 冻结的基准、具名映射、角度、预算、时间、模型摘要与场景 |
| `candidates.json` | 去重候选、原始请求别名、超限/端点碰撞/连续路径淘汰原因、选中角色 |
| `poses.csv` | 选中姿态的14轴rad值及训练/验证身份 |
| `design.npz` | 选中姿态、Pinocchio静态回归量、固定参数尺度与nominal重力预测；不是实测真值 |
| `plans/*/motion.json` | 共用Motion格式、正反接近身份、窗口与条件 |
| `plans/*/reference.npz` | Bernstein系数与时间结点，可按既有Motion/参考格式复用 |
| `plans/*/collision_reference.json` | 完整参考的nominal限位/连续碰撞证据 |
| `report.json`、`manifest.json` | 信息秩/奇异值、覆盖、总时长、权限边界及文件摘要 |

重加载复核只消费冻结文件和随包nominal模型，重新计算参考、完整路径门禁、回归量、重力及角色信息，不要求原始配置路径存在。哈希只证明文件一致性，不证明厂家语义或物理安全。

## 接入现有标定流程的边界

参考继续使用既有`Motion`，stage为`gravity`，有`batch/pose/approach`和`static_measure`窗口；Pinocchio、Coal及已有数值求解器不复制。但它是独立规划包，**不能直接作为已有`staged-calibrate`会话或S4观测协议运行**。后续现场适配需要逐条绑定实际采集与保护记录，再通过S3资格进入S4。现有重力求解器还使用测量窗口末段约0.45s；计划的1s窗口不代表本轮修改了该统计规则，未来静态缓存协议须显式约定有效样本/窗口统计。

依据[最新SDK边界](sdk_hardware_prerequisites.md#厂家答复记录2026-10-30同步)，effort是模组估算Nm，debug发布可能重复缓存，stamp仅为发布时间。不能把重复帧当独立采样、直接按stamp求导，或让仅有发布时间的数据自动满足S3。新帧/缓存年龄、尺度/偏置、补偿/滤波、实际版本、真实模型/夹具和停止条件仍待闭合。现场前两步方向/零位与频率/整体响应仍需完成，本预设不替代它们，也不改变S2 localhost限制。

## 本机验证记录

初次`artifacts/static_field_nominal_v1`使用历史Mock基准，肩部向内的诊断方向无合格点，报告false保留；v2调整nominal基准后参考通过，但组合验证池每臂秩13，保留其原始报告。最终结果以`artifacts/static_field_nominal_v3`与其独立review为准；v3训练/验证均覆盖每臂14个静态可观测方向。所有产物属于本机离线参考设计，不代表现场数据或新P0最终验收。

v3从570个去重候选中选择64个姿态、128条正反参考，41个候选因端点碰撞/余量或限位等原因淘汰，其余未选点不声称完整路径合格。每臂24训练+8验证，均达到秩14；计划总时长1268.92s（约21分9秒），左臂约635.04s、右臂约633.88s，实际测量窗口合计128s，不包含现场准备/人工检查/重试。

普通重加载与禁止访问原配置、`evaluation/`和P0 R4目录的新进程复核均通过，重算128条路径，回归量和nominal重力差均为0，结果分别在`artifacts/static_field_nominal_v3_review`和`artifacts/static_field_nominal_v3_isolated_review`。复核没有采集或拟合。

完整Python回归390项通过（14条已有Matplotlib/Pyparsing弃用警告）；随后补充复核输出不能写入冻结输入的保护，更新后的16项专项全部通过。证据分别为`artifacts/static_field_tests_v2/full.xml`和`artifacts/static_field_tests_v3/focused.xml`。本轮没有修改C++力学/积分、既有采样政策或P0正式测试，未重跑114项历史数值交付；汇总见`artifacts/static_field_delivery_v1/delivery.json`。
