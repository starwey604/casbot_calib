# 📋 SDK 能力现状与实机接入核对清单

本文档汇总了目前**已经向厂家确认的接口事实**、**当前软件采用的默认假设**，以及你到现场接入实机时需要重点核对的问题。

---

## ✅ 一、目前已确认的 SDK 与控制事实

根据前期源码排查与厂家沟通，以下机制已确认并写入当前联调配置：

1. **MIT 五字段本地混控（已确认）**：
   * CASBOT 主机接收 `/upper_body_debug/joint_cmd` 中的 `position, velocity, kp, kd, effort` 五个数组，直接转发给**因克斯（ENCOS）关节模组**。
   * 模组驱动器在本地基于编码器反馈计算 PD 并叠加前馈力矩：
     $$\tau_{\text{out}} = K_p(q_{\text{ref}} - q) + K_d(\dot{q}_{\text{ref}} - \dot{q}) + \tau_{\text{effort}}$$
   * 支持设 `kp = kd = 0`（纯前馈力矩输入）；主机自身**不会**自动叠加重力或摩擦补偿。
2. **位置插值（厂家已说明）**：
   * 主机仅对下发的 `position` 指令做线性插值并更新到 **1000Hz**；客户端默认按 **500Hz** 发送指令。
   * 切入上身调试模式（`/motion/upper_body_debug`）到收到第一帧有效指令前，主机会保持原有目标/输出。
3. **只发双臂 14 轴（已确认）**：
   * 上身控制消息只填左右臂 14 个关节名称与数值，不填腰部、头部和灵巧手。
4. **反馈力矩来源（厂家已说明）**：
   * 反馈中的 `effort` 来自因克斯模组驱动器内部估算（单位 `Nm`），机器人本体**没有**独立扭矩传感器。
5. **反馈频率与时间戳（厂家已说明）**：
   * 主机**不提供**底层 4kHz 高频原始日志，也没有每轴独立的新帧采样序号或缓存年龄字段。
   * `/motion/joint_state` 和 `/motion/debug/joint_state` 虽按 1000Hz 发布，但可能重复发送最新缓存帧；消息中的 `header.stamp` 是 **ROS 发布时刻**，而非电机底层采样时刻。

## 🔍 二、现场接入实机时重点核对的事项

到现场连接实机后，建议結合 `fieldwork` 只读工具和 GUI 调参台重点确认以下几项：

| 序号 | 核对项 | 现场怎么测 / 需要确认什么 |
| :--- | :--- | :--- |
| **1. 网络与域号** | `ROS_DOMAIN_ID` 与话题发布 | 向现场工程师确认机器人的 `ROS_DOMAIN_ID`，运行 `fieldwork/run.sh preflight` 确认 `/joint_states`、`/motion/status` 正常收数，且没有其它外部节点同时在往 `/upper_body_debug/joint_cmd` 发指令。 |
| **2. 关节 ID 与方向** | 14 轴名称映射、正负方向、零位 | 在 GUI 中点“连接 / 读取”，核对 3D 模型姿态与实机是否一致；逐轴用小幅滑条或 1° 短轨迹往返，确认实机每个关节的运动方向与模型一致。 |
| **3. 腰部固定状态** | 腰部抱死时的驱动器设置 | 双臂标定通常用夹具机械抱死腰部。虽然我们只发双臂 14 轴，但需和现场确认：**未指定的腰部轴在切入上身调试模式后，驱动器是保持原位、释放还是归零？** 避免腰部电机跟机械夹具较劲导致过流报错。 |
| **4. 断流与急停行为** | 停止发包后的机器人保护 | 当前软件在停止或异常时会停止发布消息并请求退出调试模式。需在现场小幅低速下确认：客户端断流或退出模式后，机器人是否能平稳抱闸/保持静止。 |
| **5. 力矩方向与尺度** | 反馈 `effort` 与指令 `effort` 符号/比例 | 观察静止承重时反馈 `effort` 的正负号是否与重力矩方向一致、量级是否已经折算到减速器输出侧（`Nm`），是否需要配置符号翻转或比例系数。 |
| **6. 默认 PD 增益回读** | `/motion/debug/joint_state` 是否可用 | 检查切入上身模式后，`/motion/debug/joint_state` 是否会发布当前各轴生效的默认 `kp / kd` 值。 |

## 💡 三、高频日志缺失对后续动力学标定的影响

由于机器人无法提供底层高频采样时间戳和缓存更新时间，后续标定采取以下策略：

1. **静态重力标定（H1 / H2，最稳妥）**：
   * 依靠机器人在各目标姿态停稳后的时间窗口取均值，不受缓存重复帧或微小时钟抖动影响，现场可优先跑通。
2. **匀速运动摩擦与起动摩擦（H3）**：
   * 利用较长匀速段降低时间戳抖动影响；起动摩擦采用目标轴 `Kp = Kd = 0` 叠加重力前馈与力矩斜坡进行探测。
3. **动态惯量标定（H4）**：
   * 腕部等小惯量关节对加速度相位和力矩滤波较敏感。H4 现场流程会照常完成周期激励采集、物理一致性拟合以及四组 PD/前馈控制对照，你可以直接通过实测跟踪误差（Tracking Error）对比来评估标定出的参数在实际控制中是否带来正向收益。
