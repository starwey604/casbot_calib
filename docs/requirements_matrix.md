## 状态和仓库边界

- **部分覆盖，仅合成**：存在相关子实验或接口，尚未满足整臂/实机产品验收。

## 纳入每台臂的动力学标定流程

建议把“动力学标定与验收”作为与几何标定并列、共享数据和版本的标准流程；不是给每种演奏动作复制一套模型。每台臂都要通过规定范围内的验证，但不要求每次换工具或每台同型号机器都无条件重做全部连杆参数辨识。

| 层级 | 共享 / 保存内容 | 每台臂或变更后的工作 |
| --- | --- | --- |
| 型号公共模型 | 拓扑、关节轴、参数化、坐标系约定、名义惯性与限值、前馈算法版本 | 作为有来源的先验。不能把未经核验的旧 MJCF 惯性字段当实测值；按实机型号与模型版本匹配。 |
| 单机几何与安装 | 序列号、零位、几何标定版本、安装姿态/重力方向 | 新机标定和复标后更新。改变这些输入后重新验证相关动力学项。 |
| 单机驱动与摩擦 | 电流—输出力矩增益、时序、模式、滤波/限幅、摩擦参数与温度适用范围 | 每台完成规定检查及必要辨识。固件、控制周期或驱动配置改变后重做受影响检查。内环 PI 的可调性仍由实际能力决定。 |
| 单机刚体参数 | 可辨识基参数或经验证可用的型号先验、残差与适用工况 | 每台做独立轨迹/构型验证；先验不满足验收或装配/负载明显改变时执行完整或受约束更新。未辨识的参数标注来源。 |
| 工具/负载 | 工具 ID、安装变换、质量/一阶矩/惯量的可辨识子集及来源 | 换工具先匹配已有包并快速验证；未知工具执行负载辨识。不能仅凭同一工具名称跳过检查。 |
| 伺服配置与任务验收 | PD、前馈开关、限制、轨迹/规划器版本及独立测试结果 | 绑定已验证的动力学包，检查跟踪、过冲/振动等任务指标；不把 PD 优化结果当成物理参数。 |

计划流程：**设备/驱动检查 → 几何与坐标系确认 → 动力学/摩擦辨识或先验验证 → 工具负载确认 → 冻结参数独立验证 → 前馈与 PD 对照 → 参数包交接**。工厂首次标定、现场复标与换工具快速流程使用同一模型/数据格式，按触发原因选取必要协议。

### 科氏项如何进入标定

R1已采用统一的刚体逆动力学表达；后续辨识沿用此模型，而不是把“重力”“科氏”各拟合成一组互不相关的常数：

`tau_model = M(q;theta)*ddq + h(q,dq;theta) + tau_gravity(q;theta,gravity_world,base_pose) + tau_friction(dq,T;phi)`

- `theta` 是可辨识刚体参数；`M`、速度耦合向量 `h` 和重力由同一模型导出。`h=C(q,dq)*dq` 包含科氏/离心效应，重点验证这个力矩向量，不把不唯一的 `C` 矩阵本身当独立标定对象。
- `phi` 是单机摩擦参数。驱动增益/时序另存，不混入惯性或摩擦参数吸收误差。为避免符号混淆，电流—力矩增益称 `gain`/`g_out`，重力项称 `tau_gravity`。
- 工具惯性可并入该次计算的刚体模型，也可作为单独负载贡献相加，选定一种方式并避免重复计入。转子折算惯量同样只计一次。
- 已知附加惯量提供驱动尺度；静态/低速姿态覆盖支持重力与摩擦实验；多关节动态激励支持惯性和速度耦合的可辨识部分。不能把这些实验混为一次无约束联合拟合。
- 模型结构/算法可以同型号共享，参数是否可复用由逐机、逐工具的独立验证决定。科氏项在运行时随姿态/速度变化，不是“每个关节标一个科氏系数”。

### 建模与基础验证交付边界

对应的具体实现拆分见 [整臂五轮计划](whole_arm_calibration_plan.md)，从 R1 统一内核开始。以下为 CAL-02、CAL-03、VAL-01 的总体基础范围，分轮交付，不承诺在单轮全部实现：

1. 确定多关节状态、模型来源和分项逆动力学接口；先用独立可解析的二连杆模型验证重力、惯性和非零速度耦合，再接七轴模型。基座姿态、工具、几何和动力学版本必须可追溯。
2. 保持 Mock 和未来实机共用同一前馈计算接口；C++ 负责机械过程与在线计算，Python 负责离线辨识和实验，MuJoCo 只读渲染。具体刚体库选型在这一阶段评估，不在本表中宣称已经接入。
3. 补充可配置摩擦模型，分开验证黏性/库仑与 Stribeck 增量，给出低速激励/可辨识性条件；温度只在有数据支持的范围内参数化。
4. 增加纯反馈、重力、重力+摩擦、完整逆动力学等分项对照。在相同 PD 和限制下，冻结模型验证独立轨迹，再单独评价调 PD 的收益；建立关掉速度耦合项的负对照。
5. 使用独立解析基准、能量/物理一致性和跨构型预测检查，防止只做同一模型采样后原样拟合的往返自证。无实际数据时仍只出合成结果，不能将未知产品阈值改成“已通过”。

上面是建模与基础验证范围，不等于同时完成产线放行、全参数辨识、现场 EtherCAT 接入、抑振控制或安全认证。

## 需确认的验收定义与阶段依赖

1. **AP与位置RMSE**：文件§2以AP描述0.4/0.7 mm目标，KIN-1以独立验证位置RMSE给出相同数值。两者分别记录，确认承诺指标、计算方法及适用测试集后再配置放行规则；RP单列。本表转录的是文件要求，尚未据标准原文核定完整试验规程。
2. **P0对P1的模型依赖**：CTRL-1在P0，完整DYN-1在P1。建议P0先交付可追溯的基础模型、前馈接口与动态基线，P1完成整臂辨识和负载/传动补偿；保留源优先级，不把建议当原需求变更。
3. **待定动态目标**：力矩残差、跟踪改善、换工具耗时、抑振、过冲、检测/停止和力控指标均维持TBD。原E实验的“改善≥20%”不是CTRL-1产品指标，且其对照不是纯反馈。
4. **实时预算**：1 kHz与处理器余量≥30%照录。目标处理器、核心/线程、整周期负载和余量定义待明确；平均离线耗时或单次前馈耗时不能独自证明达标，软实时测量也不能直接证明硬实时最坏界限。
5. **几何专属约束**：≤60 min是KIN-1几何标定节拍，不自动成为整套动力学标定的时长承诺；≤200是该辨识的条件数目标，不直接套到当前不同缩放的SVD判据。≤2×重复性需先定义参数单位、归一化和变化度量。
6. **IK判据方向**：KIN-4原文对成功率和耗时共用“≤[目标值待确认]”；成功率的目标方向需要澄清后才能成为自动判据。
7. **观测与职责**：力传感器是否采用、两侧编码器能力、工具实物参数、各外部工作包负责人和安全评估均待确认；当前匹配空扫的单弦事件代理不承担碰撞安全验收。
